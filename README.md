# Vējiņu kauss 2026 — KP izvietošanas rīks

## Ātrā palaišana
1. Augšupielādē `index.html` un `lof-map.jpg` vienā GitHub Pages mapē.
2. Atver lapu datorā vai telefonā caur HTTPS.
3. Spied ⚙️ un izveido 4–6 piesaistes punktus:
   - vispirms pieskaries precīzam objektam LOF kartē;
   - pēc tam tam pašam objektam pamatkartē.
4. Kad RMS kļūda ir pietiekami maza, spied **Kopēt instruktora saiti**.
5. Nosūti šo saiti instruktoriem vai izveido QR kodu.

## Instruktora lietošana
- Atver kopīgo saiti.
- Spied **Sākt GPS** un atļauj atrašanās vietu.
- Izvēlies KP vai spied **Tuvākais**.
- Rīks rāda attālumu, virzienu un GPS precizitāti.
- Pēdējiem metriem atver **LOF** fragmentu.
- Pēc izvietošanas spied **Izvietots**.

## Svarīgi
- GPS telefonā mežā parasti nav centimetru precizitātes. Pēdējos metros vienmēr salīdzini LOF reljefa objektu ar apkārtni.
- Geolocation pārlūkā parasti darbojas tikai HTTPS vietnēs (GitHub Pages ir HTTPS).
- “Izvietots” statuss šajā versijā ir lokāls katrā telefonā.
- LVM GEO WMS ir papildu slānis. Ja pārlūks nevar nolasīt GetCapabilities CORS dēļ, izmanto OSM/satelītkarti; pašas KP koordinātes no tā nemainās.
